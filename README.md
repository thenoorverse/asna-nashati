# أصنع نشاطي | استوديو الأنشطة التعليمية الذكية

**أبدع • صمّم • علّم • قيّم**
**كل مهارة تستحق نشاطًا يناسبها**

منصة عربية (RTL) لمعلمات التربية الخاصة — إنتاج أنشطة مصورة وتفاعلية وأوراق عمل A4 قابلة للطباعة.

تصميم وإشراف: أ/ عائشة البحيري

## التشغيل السريع (وضع Demo — بدون أي مفاتيح)

```bash
npm install
npm run dev
# http://localhost:3000
```

يعمل فورًا: الصفحة الرئيسية، لوحة التحكم، الاستوديو بخطواته الخمس، ٨ محركات أنشطة،
وضع الطالبة، التقارير، ٨ قوالب حقيقية، والطباعة A4 — كلها ببيانات محلية (localStorage).

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | التطوير |
| `npm run build` / `npm start` | الإنتاج |
| `npm test` | اختبارات الوحدات (Vitest) |
| `npm run db:check` | التحقق من ترحيلات SQL + سلوك RLS على Postgres حقيقي (PGlite) |
| `npm run e2e` | اختبارات النهاية للنهاية (تتطلب أولًا: `npx playwright install chromium`) |

```

  app/            الصفحات (App Router): الرئيسية، dashboard، studio، play/[id]، templates، reports، suggest، settings

  lib/
    types.ts      الأنواع + مستويات الدعم
    schemas.ts    التحقق Zod

```

## النشر على GitHub Pages (موقع ثابت — بدون Vercel)

المشروع مُصدَّر كموقع ثابت (`output: 'export'`) ويعمل بالكامل على GitHub Pages:

```bash
npm run build   # يُنتج مجلد out/
```

- الرابط بعد النشر: **https://thenoorverse.github.io/asna-nashati/**
- ملف `.github/workflows/deploy.yml` يبني ويفحص (`npm test` + `npm run db:check`) وينشر تلقائيًا عند الدفع لـ `main`.
- متغير البناء `NEXT_BASE_PATH=/asna-nashati` يُضبط في الـ workflow فقط — التطوير محليًا يبقى على الجذر.
- مسارات التشغيل بصيغة Query (`/play?id=...`) لتعمل على الاستضافة الثابتة، بما فيها الروابط المباشرة والتحديث.
- للتفعيل أول مرة: Settings → Pages → Source: **GitHub Actions**.
- (اختياري) مفاتيح Supabase عبر Secrets، وإضافة رابط الموقع لقائمة Redirect في Supabase.

## Supabase (اختياري — بدونه يعمل وضع Demo تلقائيًا)

انسخ `.env.example` إلى `.env.local` وعبّئ المفاتيح، ثم طبّق الترحيلات بالترتيب:
`supabase/migrations/001_schema.sql` ثم `002_reports_admin_storage.sql`.
التفاصيل في `supabase/README.md`.

عند تسجيل الدخول بحساب Supabase: يُقرأ الدور من جدول `profiles`، وتُحفظ الأنشطة
والأسئلة والمحاولات والاستجابات في الجداول مع عزل RLS لكل معلمة، وتُرفع الصور
إلى الحزمة الخاصة `teacher-uploads` وتُعرض بروابط موقّتة. بدون جلسة يبقى العمل محليًا.

## ما يحتاج إعدادًا خارجيًا

- **Supabase**: مشروع + مفاتيح + تطبيق الترحيلات (الواجهة والـ RLS جاهزة، والوضع المحلي يعمل بدونها).
- **الذكاء الاصطناعي**: صفحة «اقترحي لي نشاطًا» تعرض حالة «غير مفعّلة» بصدق حتى تُضبط `AI_API_KEY` على الخادم.
- **النشر**: `npm run build` ثم أي استضافة تدعم Next.js (Vercel recommended).
